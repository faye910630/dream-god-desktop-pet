# 夢境神明 像素桌寵

一隻會在 Windows 桌面上生活的像素小神明。她面無表情地在工作列上走來走去，會爬上視窗頂端散步，也會在桌面上種月光花。夜裡可以打開下雪的白色宮殿，跟她說說話。

![動作預覽](動作預覽.png)

## 功能

- **桌面散步**：在工作列上左右走動，會爬上視窗邊框，在視窗頂端散步；拖動視窗時她會跟著移動。
- **種月光花**：偶爾蹲下來種月光花；花會從發芽、長花苞、開花，最後在夜裡發光。點花可以摘下來。
- **流星**：偶爾有流星劃過桌面，點一下可以接住、許願（心情會上升）。
- **躺睡**：體力不足或太久沒人理會時，她會側躺在枕頭上睡覺，恢復體力。
- **照顧系統**：飽食、清潔、心情、體力四項狀態會隨時間下降，關掉程式後也會繼續計算。
- **下雪的白色宮殿**：雙擊她打開照顧面板——夜空飄雪的白色宮殿、狀態條、照顧按鈕，以及簡易對話。
- **開機自動啟動**：右鍵選單可勾選「開機自動啟動」（寫入 Windows 啟動資料夾）。
## 操作

| 動作 | 效果 |
|---|---|
| 點一下 | 摸摸頭，她會回話 |
| 拖曳 | 把她拎起來，放開後會掉下來 |
| 雙擊 | 打開「無夢之夢・雪白宮殿」 |
| 右鍵 | 餵食、洗澡、玩耍、睡覺、種花、流星、大小、開機啟動、關閉 |
| 點流星 | 接住流星，心情 + |

在小屋對話框輸入「吃／澡／玩／睡／流星」等關鍵字，她會一邊回覆一邊執行動作。

## L2D 點陣桌寵（8 視圖版，實驗中）

`l2d_pet.pyw`：使用 `assets/six_views/l2d_psd` 的 8 個視圖，自動轉成 **64×64 點陣圖**（以 2 倍顯示為 128px），再用類 Live2D 參數（呼吸、頭部擺動、身體前傾、頭髮／裙擺物理、小翅膀）做整數像素變形。

**動作**：左右走路（前後腳交替、手反向擺）、轉身／轉圈、彈跳、前空翻、側翻、飛到螢幕頂端倒吊、拖曳甩動、邊走邊種月光花（會發芽→長葉→花苞→開花，夜裡發光）。

**互動**

| 互動 | 說明 |
|---|---|
| 視線 | 頭會跟著滑鼠轉（右鍵可關閉） |
| 跟著滑鼠走 | 滑鼠在動、離她夠遠時，她會默默左右走過去，停在滑鼠下面盯著看（右鍵可關閉） |
| 吃 | 白色星星糖果從天上掉下來，她彎腰撿起、用袖子捧到嘴邊一口一口吃掉（飽食＋） |
| 睡 | 搬出一張月光花小床（床頭、床尾都有月光花，夜裡發光），蓋好被子冒 Z，睡 1.5～3 分鐘；點一下會醒（體力＋） |
| 洗澡 | 頂著泡泡、冒泡泡，最後轉圈甩水（清潔回滿） |
| 爬視窗 | 走到某個視窗旁沿邊緣爬上去，在視窗頂端散步；拖動視窗她會跟著走，關掉視窗她會掉下來 |
| 跌倒 | 走路時偶爾會撲倒（心情－） |
| 說話 | 頭上冒點陣字泡泡；可在對話框輸入「吃／洗澡／睡／爬／跳／翻／轉／種花…」讓她照做 |

**角色**：朵莉姆——花仙之中、夢境裡的神明，背上有白色半透明的翅膀（平常輕輕拍，在空中拍得快，飛上螢幕頂端時用力拍）。

**個性**：不善言辭、無口、面癱。話很少、大多是「……」開頭的短句；被點只會歪頭盯著你，不會笑也不會跳。

**月光花山谷**：雙擊她打開「無夢之夢・月光花山谷」——永遠是黑夜、開滿月光花的黑色山谷，顯示飽食／清潔／心情／體力，並有互動按鈕與對話框。山谷裡的她和桌面上的她同步：吃飯、洗澡、跌倒、睡覺、翻滾、倒吊都會在山谷裡演出，左右位置也跟著桌面上的位置移動。

在山谷畫面裡也可以直接抓住她拖動，桌面上的她會跟著移動。

**跳舞**：配著程式合成的原創音樂盒舞曲（120 BPM）左右搖擺、側步、小跳、轉圈，身邊飄出音符，最後擺姿勢收尾。

**演奏樂器**：抱著月光小豎琴，用袖子撥弦，彈一首原創搖籃曲（豎琴音色，撥弦動畫和音符跟著每個音同步）。右鍵選單的「聲音」可以關掉音樂。

**花束**（右鍵選單「花束」）：拿出花束後，她會走過去撿起來抱一抱再放下；也可以用滑鼠拖。對話輸入「抱月光花／抱布偶」會抱抱，「收花束／收布偶」會收起。

所有配件都有月光花：星星糖、泡泡、月光花、小豎琴、月光花小床。

**山谷裡的對話**：在山谷畫面點她一下（不拖動），會像 RPG／養成遊戲一樣打開對話——她以左 45 度的大張立繪出現，底部是對話框與名牌「朵莉姆」，文字逐字打出；選項有「最近好嗎？」「說說夢的事」「一起玩吧」（跳舞／彈豎琴／抱月光花）「（摸摸頭）」「再見」。可用滑鼠、方向鍵、Enter／空白鍵操作；下方輸入框說的話也會顯示在對話框裡。

**開機自動啟動**：右鍵選單勾選「開機自動啟動」，會在 Windows 啟動資料夾放一個月光花圖示的捷徑「朵莉姆 L2D 桌寵」；也可以用 `python l2d_pet.pyw --autostart on`／`off`。

**小遊戲「接星星」**：在永夜山谷的地面左右移動，接住落下的白色星星糖（+1）與金色流星（+3），避開紫色的惡夢球；漏接或碰到惡夢會扣心（共 3 顆），越玩越快。

**換裝**：右鍵選單「換裝」或山谷裡的下拉選單——哥德黑（原本）、白色洋裝、婚紗（半透明頭紗＋花冠）。換好會轉一圈；選擇會保存，小遊戲裡的她也會穿同一套。

**小遊戲「雲端之夢」**：右鍵選單或山谷的按鈕開啟。她會自動往上彈，用 ← → / A D 或滑鼠左右移動，從月光花山谷的葉子、穿過薄霧與雲海，一層一層跳到「雲端之上」的星空（約 300 m）；沿途收集白色星星糖，夢泡泡踩一次就會破。玩完會加心情，最佳紀錄會保存。

**Unity 版小遊戲**：`unity/DreamGodGames` 是 Unity 6 專案（6000.6.10f1），內含「雲端之夢」與「接星星」。建置好 `unity/Build/DreamGodGames.exe` 後，桌寵開小遊戲會優先用 Unity 版（帶入目前的衣服），關掉後讀取成績加心情；沒有建置時會用 Python 版。

```powershell
python l2d_pet.pyw --export-unity          # 把點陣角色（每套衣服）、翅膀、星星糖、月光花等輸出到 Unity 專案
& "C:\Program Files\Unity\Hub\Editor\6000.6.10f1\Editor\Unity.exe" -batchmode -quit -projectPath unity\DreamGodGames -executeMethod BuildScript.Build -logFile unity\build.log
```

也可以在 Unity 編輯器選單 **DreamGod → Build Windows** 建置。Unity 版啟動參數：`-game cloud|stars`、`-outfit N`、`-result 成績.json`。

**圖示**：所有視窗、工作列、Unity 執行檔都用月光花圖示（`assets/icons/moonflower.ico`）。專案根目錄的「夢境神明 L2D 桌寵」「夢境神明桌寵」捷徑也是月光花圖示（捷徑含本機路徑，不納入 git）。

操作：點一下＝摸頭（睡著時是叫醒）、雙擊＝打開山谷、拖曳＝抓起來甩、右鍵＝選單。

```powershell
pythonw l2d_pet.pyw                       # 啟動（或雙擊 啟動L2D桌寵.bat）
python l2d_pet.pyw --home                  # 啟動並直接打開月光花山谷
python l2d_pet.pyw --do game               # 啟動後直接做某個動作（eat / bath / sleep / climb / game …）
python l2d_pet.pyw --demo demo.gif         # 不開視窗，輸出示範動畫
python l2d_pet.pyw --rebuild-sprites       # 重新從 PSD 預覽圖產生點陣圖
```

點陣圖存在 `assets/pixel64/*.png`，可直接逐點修改（例如補眼睛），桌寵會優先讀取；`--rebuild-sprites` 會覆蓋它們。
存檔：`%APPDATA%\DreamGodL2D\`（`state.json` 照顧數值、`flowers.json` 月光花）。

## 執行方式

### 打包版（推薦）

雙擊 `dist\夢境神明桌寵.exe`，或先建置：

```powershell
pip install pillow pyinstaller
.\build_exe.bat
```

### 朵莉姆 L2D 桌寵（exe）

```powershell
.\build_l2d_exe.bat
```

輸出 `dist\朵莉姆桌寵\`：裡面的 `朵莉姆桌寵.exe` 是桌寵本體（月光花圖示），`unity\Build\` 是 Unity 小遊戲。整個資料夾一起複製到別台電腦就能用（不需要安裝 Python）。

### 原始碼版

需要 Windows 和 Python 3（含 tkinter）以及 Pillow：

```powershell
pip install pillow
```

雙擊 `啟動桌寵.bat`，或執行：

```powershell
pythonw fairy_pet.pyw
```

無主控台啟動也可：

```powershell
wscript tools\start_desktop_pet.vbs
```

存檔位置：`%APPDATA%\FairyPet\`（狀態與種下的月光花）。  
開機捷徑：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\夢境神明桌寵.vbs`

## 檔案

- `fairy_pet.pyw`：桌寵主程式
- `chibi_base.png`：角色像素圖
- `spritesheet.png` / `spritesheet.json`：所有動作的精靈圖表，可匯入 Unity 等引擎
- `valley.png`：下雪白色宮殿背景
- `fonts/Cubic_11.ttf`：介面像素字型（俐方體11號／Cubic 11，SIL OFL）
- `fonts/OFL.txt`：字型授權
- `tools/start_desktop_pet.vbs`：無視窗啟動腳本
- `啟動桌寵.bat`：快速啟動
