# 夢境神明 像素桌寵

一隻會在 Windows 桌面上生活的像素小神明。她面無表情地在工作列上走來走去，會爬上視窗頂端散步，也會在桌面上種月光花。

![動作預覽](動作預覽.png)

## 功能

- **桌面散步**：在工作列上左右走動，會爬上視窗邊框，在視窗頂端散步；拖動視窗時她會跟著移動。
- **種月光花**：偶爾蹲下來種月光花，花會從發芽、長花苞、開花，最後在夜裡發光。點花可以摘下來。
- **照顧系統**：飽食、清潔、心情、體力四項狀態會隨時間下降，關掉程式後也會繼續計算。
- **無夢之夢**：雙擊她打開照顧面板，裡面是月光花谷的夜景、狀態條，以及餵食、洗澡、玩耍、睡覺按鈕。

## 操作

| 動作 | 效果 |
|---|---|
| 點一下 | 摸摸頭 |
| 拖曳 | 把她拎起來，放開後會掉下來 |
| 雙擊 | 打開「無夢之夢」照顧面板 |
| 右鍵 | 餵食、洗澡、玩耍、睡覺、種月光花、調整大小、關閉 |

## 執行方式

需要 Windows 和 Python 3（含 tkinter）以及 Pillow：

```powershell
pip install pillow
```

雙擊 `啟動桌寵.bat`，或執行：

```powershell
pythonw fairy_pet.pyw
```

存檔位置：`%APPDATA%\FairyPet\`（狀態與種下的月光花）。

## 檔案

- `fairy_pet.pyw`：桌寵主程式
- `chibi_base.png`：角色像素圖
- `spritesheet.png` / `spritesheet.json`：所有動作的精靈圖表，可匯入 Unity 等引擎
- `valley.png`：月光花谷背景
