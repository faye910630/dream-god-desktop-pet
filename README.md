# 夢境神明 像素桌寵

一隻會在 Windows 桌面上生活的像素小神明。她面無表情地在工作列上走來走去，會爬上視窗頂端散步，也會在桌面上種月光花。夜裡可以打開下雪的白色宮殿，跟她說說話。

![動作預覽](動作預覽.png)

## 功能

- **桌面散步**：在工作列上左右走動，會爬上視窗邊框，在視窗頂端散步；拖動視窗時她會跟著移動。
- **種月光花**：偶爾蹲下來種月光花；花會從發芽、長花苞、開花，最後在夜裡發光。點花可以摘下來。
- **流星**：偶爾有流星劃過桌面，點一下可以接住、許願（心情會上升）。
- **躺睡**：體力不足或太久沒人理會時，她會側躺在枕頭上睡覺，恢復體力。
- **照顧系統**：飽食、清潔、心情、體力四項狀態會隨時間下降，關掉程式後也會繼續計算。
- **下雪的白色宮殿**：雙擊她打開照顧面板——夜空飄雪的白色宮殿、狀態條、照顧按鈕，以及簡易對話。
- **開機自動啟動**：右鍵選單可勾選「開機自動啟動」（寫入 Windows 啟動資料夾）。
## 操作

| 動作 | 效果 |
|---|---|
| 點一下 | 摸摸頭，她會回話 |
| 拖曳 | 把她拎起來，放開後會掉下來 |
| 雙擊 | 打開「無夢之夢・雪白宮殿」 |
| 右鍵 | 餵食、洗澡、玩耍、睡覺、種花、流星、大小、開機啟動、關閉 |
| 點流星 | 接住流星，心情 + |

在小屋對話框輸入「吃／澡／玩／睡／流星」等關鍵字，她會一邊回覆一邊執行動作。

## 執行方式

需要 Windows 和 Python 3（含 tkinter）以及 Pillow：

```powershell
pip install pillow
```

雙擊 `啟動桌寵.bat`，或執行：

```powershell
pythonw fairy_pet.pyw
```

無主控台啟動也可：

```powershell
wscript tools\start_desktop_pet.vbs
```

存檔位置：`%APPDATA%\FairyPet\`（狀態與種下的月光花）。  
開機捷徑：`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\夢境神明桌寵.vbs`

## 檔案

- `fairy_pet.pyw`：桌寵主程式
- `chibi_base.png`：角色像素圖
- `spritesheet.png` / `spritesheet.json`：所有動作的精靈圖表，可匯入 Unity 等引擎
- `valley.png`：下雪白色宮殿背景
- `fonts/Cubic_11.ttf`：介面像素字型（俐方體11號／Cubic 11，SIL OFL）
- `fonts/OFL.txt`：字型授權
- `tools/start_desktop_pet.vbs`：無視窗啟動腳本
- `啟動桌寵.bat`：快速啟動
