# 未命名的作品 62 — L2D

```
web/index.html            網頁版 L2D（雙擊開啟）
web/parts.js              網頁版用的零件（由 tools/export.py 產生）
cubism/psd62_cubism.psd   給 Live2D Cubism Editor 匯入的整理版 PSD
tools/export.py           從原始 PSD 重新產生以上兩者
```

## 網頁版（web/index.html）

用原圖的拆件直接做網格變形，參數仿照 Cubism 的標準參數。

- **頭部**：角度 X／Y／Z，前髮、臉、後髮的景深不同，轉頭時有立體感
- **眼睛**：左右眼分開開閉；閉眼時上眼皮往下翻轉蓋住，下眼皮和下睫毛淡出；眼球 X／Y（整顆虹膜一起動，裁在眼眶內）
- **臉**：眉毛（額頭上的麻呂眉）上下、嘴巴開合、嘴型、腮紅
- **身體**：身體 X／Z、呼吸、頭上翅膀
- **物理**：雙馬尾、辮子、緞帶、側髮、瀏海、袖子、裙子、領結
- **動作**：說話、開心、拍翅膀、點頭、搖頭、眨眼；點頭部或身體也會有反應
- 右側滑桿可以手動控制（拖過的參數會變粉紅色），按「全部交回自動」恢復；另外有網格顯示、背景切換（含綠幕，方便錄影或直播去背）

## Cubism 用 PSD（cubism/psd62_cubism.psd）

2048×2048、RGB 8bit，可直接匯入 Cubism Editor 開始做網格與變形器。

**和原始 PSD 的差別**
- 每個圖層都有部位名稱，依部位分成 8 個群組：後髮、脖子、臉、前髮、眼睛_L、眼睛_R、身體、頭上翅膀
- 左右成對的部位拆成 `_L`／`_R` 兩層（以**畫面**左右為準），例如眼睛各層、眉毛、耳朵、辮子、緞帶、側髮、袖子、腿、外裙、翅膀
- **剪切遮罩已烘焙**：Cubism 匯入時不讀 PSD 的剪切遮罩，所以剪切圖層（虹膜、瀏海陰影、臉上髮影等）已經先裁好。在 Cubism 裡要讓虹膜不跑出眼眶，請另外把虹膜各層的「剪切 ID」設成眼白
- **補圖**：被上層蓋住、原本沒上色的地方用鄰近顏色補滿，例如辮子上半段、腿根、外裙中間、後腦勺邊緣，以及脖子往上下延伸。靜止時畫面和原圖一樣，動起來不會露出空洞
- 脖子移到後腦勺之上（原本後腦勺會蓋住脖子）
- 刪掉多餘筆畫：後髮尾線左右兩條弧線、裙子附近和洋裝上的雜線
- 頭髮高光層裡的眼睛反光拆成獨立圖層，放進眼睛群組，閉眼時才能一起隱藏

**隱藏的參考圖層**（預設不顯示，可用來做表情或對照）
- `閉眼(上眼皮翻轉,參考)_L／_R`：上眼皮以 y=618 為軸垂直翻轉後的閉眼樣子。可以直接當閉眼的圖層用，或當作變形的目標形狀
- `張嘴(參考)`：張嘴時的口內（淺粉色，有小虎牙）

**注意**
- `頭髮高光`、`虹膜高光A／B`、`眼睛反光(髮高光層)` 是「濾色」混合模式。若你的 Cubism 版本不支援濾色，匯入後請改成「加算」並調低不透明度
- 閉眼時建議把 `下眼皮`、`下睫毛`、`眼皮高光點`、`眼睛反光` 一起淡出

## 重新產生

原始 PSD 有修改時：

```powershell
pip install psd-tools pillow numpy scipy
python tools\export.py "C:\Users\你的帳號\Downloads\未命名的作品 (62).psd"
```

不帶參數時預設讀取「下載」資料夾裡的 `未命名的作品 (62).psd`。圖層對應、補圖範圍、要清掉的雜線都寫在 `tools/export.py` 開頭的設定裡。
